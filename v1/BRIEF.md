# Sylvan 沉淀站 — Shape Brief

> 本文档为 shape 阶段的产出。未经显式确认前不视为锁定；shape 不写代码、不写方向合同、不写 DESIGN.md。
> 后续由 per-surface new-work 轮次落地；首轮 new-work 推荐从首页开始。

## 1. Job and Audience

- **到访者**：任意偶然发现的访客，意图不固定——可能想读一篇文章、翻翻某次旅记、看一组照片、跟一段 citywalk，也可能只是看一眼就走。无登录、无门槛、无引导漏斗。
- **站点首要任务**：让访客在**不被打扰**的前提下，沿时间序沉淀物缓慢地走。沉淀物 = 文章（文本为主）+ 旅记 / 相册 / citywalk（文本与媒体等权，路由独立但共享"影像与足迹"入口）。
- **访客模式**：本项目属于混合——首页与模块二级页是 **Experience**（让沉淀物本身领着看，界面退到边缘），文章三级页是 **Read**（让阅读体验值得停留），旅记/相册/citywalk 三级页是 **Experience + Read** 的混合（媒体领路、文本承载）。

## 2. Outcome and Proof

- **首要成功标志**：访客在首页一眼能区分"读"与"看/走"两条路径（文章入口 vs 影像与足迹入口），并被其中至少一条吸引，进入二级页。
- **次要成功标志**：进入任意模块后，访客能不靠搜索、不靠标签，沿时间序持续浏览；并在合适的位置看到关联条目（citywalk ↔ 同城市旅记，旅记 ↔ 同月份相册，文章 ↔ 相关旅记），自然进入相邻沉淀物。
- **真实证据**：
  - 文章来自 GitHub repo（Astro Content Collections），每篇有 frontmatter（title / date / tags? / related?）；
  - 旅记 / 相册 / citywalk 的文本字段存 Supabase，媒体走 Supabase Storage；
  - 关联条目通过显式字段（related slug / city / year-month）建立，不靠 NLP 推断；
  - Live Photo 与视频通过 Supabase Storage 公共 URL 直出。
- **产品特异性**：相比一般"个人博客 / portfolio 模板"，这个站点同时承担**慢节奏阅读**与**媒体重浏览**两条产品曲线，并在首页以单一 hero 把这两条曲线分到两条入口；相比 gabrielbeaugonin.com 那种纯影像档案，本站点有"文章"这条独立路径，因此留白与克制的尺度要适配"长文本 + 慢节奏阅读"。

## 3. Selected Direction（站点级方向意向，视觉语言待首轮 new-work 锁定）

### 3.1 Visual Authority

- **约束**：gabrielbeaugonin.com 的留白、简洁、克制、创意感是**约束**，不是成稿视觉。
- **候选视觉世界**（仅列出 5 个候选方向供首轮 new-work 收敛；shape 不锁定）：
  1. **编辑印刷感**（Editorial Ink）——衬线大标题 + 极强留白 + 单色墨色 + 网格硬约束，文字与照片都被当版面元素排；
  2. **暗色档案感**（Obsidian Luxe）——深色基底 + 高对比小字号 + 媒体大块面 + 极少色相；
  3. **瑞士栅格感**（Swiss Grid）——12 列严格栅格 + sans + 模块化切分 + 信息密度均匀；
  4. **温和自然感**（Aristotle Warm + Green）——暖白底 + 衬线 / 无衬线混排 + 单一暖色相点缀 + 圆角柔和；
  5. **极简单色感**（Quiet Mono）——单一灰阶 + 等宽数字 + 媒体边缘锐利 + 零装饰。
- **首轮 new-work 将基于这 5 个候选做收敛**；最终视觉世界在该轮由你从 mockup 中挑定，之后才落 DESIGN.md。

### 3.2 Structural / Interaction Thesis

- **首页**：单 hero 视口承载 Sylvan 签名 + 两条入口分流（**文章** 与 **影像与足迹**）。其他模块入口不重复出现在首页 hero；如需模块直达，由持久导航承担。
- **模块组织**：旅记 / 相册 / citywalk 共享"影像与足迹"首页入口块；点击进入对应模块的二级页，路由各自独立。
- **发现机制**：**主路径仍是纯时序浏览**（最新在前），无全站搜索、无标签云索引；可发现性靠"时间序 + 关联条目 + tag 聚合"承担。
  - tag 不进入首页 hero、不出现在模块二级页的入口区；
  - tag 在卡片与详情页上**作为元数据可见**（轻量字号，行尾或元数据区）；
  - tag **可点击**，跳转 `/tags/[tag]` 跨模块聚合页（按时间倒序，混合 articles / travels / albums / citywalks）；
  - 没有 `/tags` 索引页（避免变成 tag-cloud）。
- **关联条目**：citywalk ↔ 同城市旅记（同 `city` 字段）；旅记 ↔ 同月份相册（同 `year-month` 字段）；文章 ↔ 相关旅记（显式 `related` slug 数组）。关联以"延伸阅读 / 同期影像"形式出现在详情页尾部，不进入首页。

### 3.3 Sequence

1. 访客进入 `/` 首页
2. 在 hero 视口内识别两条入口，选择一条
3. 进入对应模块的二级页（时序列表）
4. 选中某条 → 进入三级详情页
5. 阅读/浏览至尾部 → 通过关联条目进入相邻沉淀物
6. 通过悬浮胶囊 header 回到首页或切到另一模块
7. 在卡片或详情页看到 tag → 点击 → 进入 `/tags/[tag]` 跨模块聚合页（按时间倒序），继续延展浏览

### 3.4 Focal Moment

- **首页 hero** 是整站唯一的"识别瞬间"。它必须在第一屏同时做到：
  - 让 Sylvan 的氛围化身份可被感知（不靠头像/照，靠版面与 giant signature）
  - 让两条入口（文章 vs 影像与足迹）在版面层级上一目了然
  - 不堆叠第三方社交/订阅按钮，不放文章摘要预览
  - **不放 atmospheric / tagline 段落**（2026-08-20 用户反馈：与 giant signature 视觉功能重叠，去掉更克制）
- 其余 surface 的 focal moment 由该 hero 的视觉语言外延而来，不再各自立旗。

### 3.5 Implementation Consequence

- 首页是后续每个 surface 的**视觉母体**；锁定首页方向 = 锁定全站栅格 / 字体 / 色板 / 留白节奏。
- 模块二级页继承首页的栅格与节奏，不另起一套设计语言。
- 三级详情页在首页母体基础上为"长内容 / 大媒体"做局部放大（阅读栏宽、媒体最大尺寸），不打破母体。
- Astro 实现阶段：首页 hero、模块二级、三级详情共用一套 design tokens；不复制样式。

- **保真度**：brief 级别，不出 mockup；mockup 在后续 new-work 轮次产出。
- **目标交付物**：本 brief 一经你确认，后续 per-surface new-work（首推首页）按此 brief 起手。
- **明确不动的部分**：
  - PRODUCT.md 已锁定的产品事实（受众 / 人物 / 语言 / 数据源 / 栈 / 范围外项）；
  - 模块边界与路由结构（已在 PRODUCT.md 中确认）；
  - "无评论、无搜索、无标签"的产品决定。
- **明确 anti-goals**：
  - 不引入会员、订阅、邮件列表；
  - 不在首页放 CTA / 推送订阅 / "订阅我" 区块；

  - 不做"博客模板"那种"近期文章 + 标签云 + 分类 + 归档"四件套。

## 5. States and Ranges

### 5.1 内容密度（已校准，作为 layout 输入）

| 模块 | 当前量级 | 1–2 年内预估 |
|---|---|---|
| 文章 | ~5 篇 | ~20–30 篇 |
| 旅记 | ~3 条 | ~10–15 条 |
| 相册 | ~1–2 年 / 月均 ~10–30 张（静态 + Live + 视频） | ~3–5 年 |
| Citywalk | ~5 条 | ~15–25 条 |

### 5.2 覆盖的 States

- **基础三态**：空 / 加载 / 错误（三模块统一）
- **相册月份无内容回退**：`/albums/2024/03` 为空时显示"该月还没有记录" + 回链到 `/albums` 二级，不留白 404
- **Live Photo 播放失败回退**：浏览器/网络不支持时回退静图 + 一行小字提示
- **不覆盖**：权限态、专家模式、批量操作、订阅态

## 6. Interaction and Layout

### 6.1 IA 与路由

```
/                              首页（hero + 两条入口）
/articles                      二级：时序列表
/articles/[slug]               三级：阅读视图
/travels                       二级：时序列表
/travels/[slug]                三级：路线 / 文字 + 媒体
/albums                        二级：年 → 月 精选切片（带"查看更多"）
/albums/[year]/[month]         三级：当月完整网格（可日历 UI，形态待视觉方向轮次决定）
/citywalks                     二级：时序列表
/citywalks/[slug]              三级：路线 + 媒体
/tags/[tag]                    跨模块 tag 聚合页（按时间倒序；无索引页）
```

### 6.2 首页版式（方向意向，待 new-work 出 mockup）

- **首屏 hero**：**Giant Sylvan 签名作为焦点**（Cormorant Garamond italic，大字号）+ 两条入口分流块（**文章** / **影像与足迹**）。**不放 atmospheric / tagline 段落**（2026-08-20 用户反馈：与 giant signature 视觉功能重叠，去掉更克制）。
- **次屏**：可选——最新 N 条文章 / 最新 N 张当月精选的预览缩略带；具体是否出现、出现多深，由 new-work 的视觉方向决定。
- **持久导航 — 灵动岛态 header**：模块导航（4 项：文章 / 旅记 / 相册 / Citywalk）以**悬浮胶囊**形式常驻在 viewport 顶部，不贴边、不抢 hero，作为可呼吸的次级信息层。
  - **默认态**：胶囊宽度 ≤ 内容宽，圆角饱满，半透明底 + 1px 细边框，承载 site mark（Sylvan 签名或缩写）+ 4 个模块入口（图标或短词）+ 右侧 section 指示器
  - **右侧内容区域 = 当前 section 指示，永不空**（2026-08-20 用户反馈）：在主页显示"● 主页"；滚到 featured 显示"● 近期"；在其他模块显示对应名称（如"● 文章"）。即使在 hero 视口内，胶囊处于最小存在感时，右侧指示仍可见，不为空。
  - **方向锁定：Direction A = Field Notebook（默认首次加载），Direction B = Editorial Ink（切换态）**（2026-08-20 用户决策）。
  - **滚动态**：随下滚收起为更紧凑的小胶囊（仅保留 site mark + 当前 section 指示），随上滚恢复完整宽度；过渡用缓动时长，避免跳动
  - **展开 / 反馈态**：hover / focus / 点击时胶囊短暂展开，露出模块完整中文标签；离开后回缩
  - **与 hero 的关系**：在首页 hero 视口内，胶囊处于最小存在感（透明度更低、位置更靠上或更窄），不与 hero 签名抢焦点
  - **详情页增强**：在文章 / 旅记 / citywalk 详情页，胶囊可承载轻量阅读进度（细进度条或当前位置小指示），但不抢阅读节奏
  - **相册三级页特例**：日历 UI / 网格浏览时，胶囊回到默认态，不显示阅读进度，避免与媒体浏览的视觉权重打架

### 6.3 模块二级版式

- 列表为单列时序或两列卡片网格（具体由 new-work 的视觉方向决定）。
- 每条卡片承载：标题 + 日期 + 一行摘要/拍摄地点 + 主图缩略。
- 无筛选器、无分页器（用"加载更多"或纯滚动分页，二选一由视觉方向定）。

### 6.4 三级详情版式

- **文章**：单栏阅读（栏宽 65–75ch），行高松，图注右对齐；末尾关联条目（"相关旅记 / 相关阅读"）。
- **旅记 / Citywalk**：文字 + 媒体混合流；段落间穿插照片 / Live Photo / 视频；末尾关联条目（"同期相册 / 同城 citywalk"）。
- **相册月份**：当月完整网格（可日历 UI 形态），每格承载该日的第一张 / 代表媒体；hover（桌面）/ tap（移动）触发 Live Photo 播放；点击进入 lightbox 大图 + Live Photo / 视频播放。

### 6.5 Live Photo 播放形式（已确认）

- 桌面：hover 触发播放（一秒内开始）
- 移动：tap 触发播放
- 三级页 lightbox 内：大图 + Live Photo / 视频统一播放
- 浏览器不支持时回退静图 + 提示

### 6.6 关联条目形式

- 不出现在首页。
- 在三级页尾部以"延伸阅读 / 同期影像 / 同城足迹"形式列出，每条 1 行（标题 + 日期）。
- 无算法推荐，仅显式字段（`related` slug / `city` / `year-month`）。

### 6.7 Tag 行为（A + B：可见 + 可点击聚合）

- **数据模型**：所有模块（articles / travels / albums / citywalks）都支持 `tags` 字段；多 tag 取数组形式。
  - 文章：来自 GitHub frontmatter（`tags: []`）；
  - 其他模块：来自 Supabase 文本字段。
- **卡片**：tag 以一行小字（轻量字号、低对比）出现在主图缩略下方或卡片底部；可点击。
- **详情页**：tag 显示在元数据区（标题 / 日期旁），与 hero 不抢权重；可点击。
- **不出现的位置**：首页 hero、模块二级页的入口区、悬浮胶囊 header。
- **`/tags/[tag]` 聚合页**：
  - 按时间倒序混合四个模块的内容；
  - 模块之间用极轻的分区（细线或留白，不靠色块区分）；
  - 模块类型用一致的标签或微缩图标指示，避免视觉噪声；
  - 无筛选器、无排序切换（时间倒序固定）；
  - 无分页器（"加载更多"或纯滚动分页，由视觉方向轮次决定）；
  - 顶部保留 tag 名（页面标题）+ 一行回链"← 回到 [所属模块]"，避免聚合页成为信息孤岛。

## 7. Constraints and Open Decisions

### 7.1 持久约束

- 中文（zh-CN）单一语言；
- 无评论、无搜索、无标签、无订阅；
- Sylvan 抽象人格，无头像、无社交露出；
- 视觉约束：gabrielbeaugonin.com 的留白 / 简洁 / 克制 / 创意感；
- 数据源：文章 = GitHub repo；其他模块 = Supabase（文本 + Storage）；
- **Tag 能力**：所有模块都允许有 `tags` 字段；UI 上 tag 既是可见元数据，也可点击进入 `/tags/[tag]` 跨模块聚合页；无 `/tags` 索引页；
- Phase 1 = 静态 HTML/CSS 预览；Phase 2 = Astro 最新版 + 无冲突最新依赖；
- **开源素材工作流**：mockup 与实现阶段所需的占位图片 / Live Photo / 视频，优先使用开源免费素材（Unsplash / Pexels / Pixabay 等 CC0 / 自由许可来源）。每个引用素材在交付物中保留来源 URL + 许可类型作为 provenance（来源而非生成）；如最终落地使用自有拍摄，则替换为自有资产并更新 provenance。
- **不显示阅读时间**：文章不展示 "X 分钟阅读" / reading time。沉淀站不承担 productivity frame，访客按自己的节奏读（2026-08-20 用户决策）。
- Workflow：`.impeccable/config.json` 已记录 `buildPath: "comp"`，后续 new-work 沿用。

### 7.3 本轮新增的 Open Decisions
